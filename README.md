# my-first-site

My personal portfolio, and the place I'm learning to build websites by vibecoding with Claude.

## What's in here

| File | What it does |
|------|--------------|
| `index.html` | The content: words, sections, links |
| `style.css` | The look: colors, fonts, spacing (colors are at the top) |

## Vibecoding: how to change things

Just describe what you want in plain words. For example:

- "Change my tagline to something about gaming and design"
- "Make the colors purple and pink"
- "Add a project card for my Minecraft server"
- "Add a photo of me in the hero section"
- "Explain what the `.grid` part of style.css does"

Tips:
- **One change at a time.** It's easier to see what happened and undo it.
- **Ask why.** "Explain what you just changed" is how you learn.
- **Look before you ship.** Open `index.html` in your browser to check it.

## Saving to GitHub

Ask Claude to "commit and push", or run:

```
git add .
git commit -m "describe your change"
git push
```
